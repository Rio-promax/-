# 可分享的产品内容

存放产品生成或导出的知识内容，与调研资料、人工笔记、源码和需求分离。

- `generated/`：产品生成的 Markdown、JSON 和可追溯来源；
- `samples/`：用于验收、演示和回归测试的样例。

手工整理的笔记和分类放在 [../笔记/](../笔记/)。产品实时数据库和知识库主档案仍位于 `product/local/`；`generated/` 是需要单独导出或分享的内容。生成内容和样例默认不进入 Git。

现有小红书验证样本与媒体证据保存在本地的 [2026-09-21 抓取集](../../../local/experiments-platform-shell/captured/2026-09-21/) 和 [2026-09-23 抓取集](../../../local/experiments-platform-shell/captured/2026-09-23/)；相关手法记录见 [09-24 方案](../2026-09/09-24_小红书收藏抓取_借签名手法与降级方案.md)。这些本地样本体积约 1.2 GB，并被既有方案引用，不复制进 Git，也不将其冒充为已发布内容。

常用证据直达：[269 条结构化分析](../../../local/experiments-platform-shell/captured/2026-09-23/xhs-all/小红书笔记结构化分析-269条.md)、[30 条结构化分析](../../../local/experiments-platform-shell/captured/2026-09-23/xhs-30/小红书笔记结构化分析-30条.md)、[269 条抓取报告](../../../local/experiments-platform-shell/captured/2026-09-23/xhs-all/抓取报告.txt)。
