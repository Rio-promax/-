## 核心用户任务

从内容接入入口准备内容，创建并跟踪处理任务，最终在知识库找到可阅读的结果；用户以“任务明确完成且结果可在知识库打开”为完成信号。

## 覆盖

### 已验证

- 三个主导航切换及平台链接/本地识别模式切换。
- 本地文本输入、查询、提交前检查、确认窗口关闭、输入保留和清空。
- 任务筛选、完成/失败详情展开、刷新反馈和完成结果跳转。
- 知识库搜索无结果、清除搜索、筛选展开、内容详情及返回。

### 部分验证

- 正常接入只验证到“确认创建任务”前。
- 历史完成和失败终态可见，但未实时跟随任务处理过程。
- 结果详情已盘点，未执行会持久化或调用模型的动作。

### 未验证

- 创建任务、重复提交、排队、实时处理、部分成功和成功入库同步。
- 处理中离开、返回、刷新及应用重启恢复。
- 重试、取消、删除、回收站恢复和批量编辑。
- 平台链接、多链接、文件、路径和格式错误分支。
- 标签、收藏夹、重新总结、局部总结及反馈提交。

## 待验证交互分支库

### 记录边界

- 本节用于生成后续交互审计的测试路径，不代表功能已实现、可用或通过验证。
- 本节所有分支默认标记为 `[U：待新 AI 任务验证]`，后续必须逐路径记录实际界面、即时反馈、处理中反馈、终态和恢复方式。
- “单条链接”指直接指向一个内容对象的链接；“集合链接”指 UP 主、收藏夹、合集、稍后再看、频道或其他可展开为多条候选的入口。
- 每条路径不只验证“能否到达下一页”，还要记录用户在当前状态下可继续触发的操作。

### B1～B9 输入组合与识别分支

```text
B1 单个有效单条链接
└─ 查询 → 1 条候选 → 查看详情 / 修改参数 / 提交 / 取消

B2 两个有效单条链接
├─ 两条均识别 → 全选 / 只选任意一条 / 逐条取消 / 全部提交
├─ 一条先返回、一条后返回 → 等待 / 先操作已完成项 / 取消整批
└─ 一条成功、一条失败 → 提交成功项 / 重试失败项 / 修改原输入

B3 三个及以上有效单条链接
├─ 全部成功 → 全选 / 反选 / 部分选择 / 全部提交
├─ 部分重复 → 跳过已有 / 复用处理中 / 重新处理
└─ 部分失败 → 仅重试失败项 / 删除失败项 / 保留整批等待

B4 单个无效、不支持或不完整链接
└─ 查询 → 原因提示 → 原地修改 / 删除 / 重试 / 打开帮助

B5 有效链接 + 无效链接
├─ 保留两条的独立状态
├─ 仅提交有效项，无效原输入保留待修改
└─ 修改无效项后重查，已成功项不应被重复创建

B6 同一内容的原始链接、短链接和带追踪参数链接
└─ 规范化 → 识别为重复 → 合并 / 保留一条 / 明确允许重新处理

B7 同一批次的跨平台链接
├─ 各平台均可读 → 统一候选列表 / 分组展示
├─ 部分平台需登录 → 保留其他平台结果 / 去连接后返回
└─ 部分平台风控或超时 → 单项重试 / 继续提交可用项

B8 链接 + 空行 + 普通文字 + 重复行
└─ 预处理 → 说明忽略项、错误项和去重结果 → 用户确认后查询

B9 查询进行中再次粘贴、删除或发起新查询
├─ 保持旧请求 → 新内容等待下次查询
├─ 取消旧请求 → 仅展示新结果
└─ 旧响应迟到 → 不得覆盖新查询会话
```

### B10～B15 集合链接与混合展开分支

```text
B10 单个 UP 主链接
├─ 识别为创作者 → 展示创作者信息 → 开始扫描 / 取消 / 返回修改
└─ 开始扫描
   ├─ 扫描中 → 等待 / 取消 / 关闭后重进 / 离页后返回
   ├─ 0 条候选 → 调整范围 / 刷新 / 退出
   ├─ 1 条候选 → 按单条候选确认
   ├─ 多条候选 → 全选 / 部分选择 / 分页 / 搜索 / 排序 / 筛选
   └─ 扫描失败或部分返回 → 重试 / 保留已取得候选 / 修复连接

B11 单个收藏夹、合集、稍后再看或频道链接
├─ 公开可读 → 扫描候选 → 选择范围 / 提交
├─ 需授权 → 去连接 / 重新授权 / 取消 → 返回原确认上下文
├─ 空集合 → 刷新 / 修改链接 / 退出
└─ 集合过大 → 限制数量 / 分页 / 时间范围 / 分批提交

B12 1 个 UP 主链接 + 1 个单条链接
├─ 单条链接先完成 → 保留候选，UP 主继续扫描
├─ UP 主先展开 → 候选组 + 单条识别中
├─ 两者都成功 → 单条候选与 UP 主候选组同屏展示
├─ 仅提交单条 / 仅提交 UP 主中的选中项 / 合并提交
└─ 任一来源失败 → 另一来源仍可操作，失败来源可独立重试

B13 多个单条链接 + 1 个集合链接
├─ 展开后按“原始输入组”保留来源关系
├─ 候选总数随集合展开而变化，用户可辨认已选数与将创建任务数
├─ 按来源组全选 / 取消，不影响其他组
└─ 集合展开部分失败 → 已成功候选与独立单条均可继续提交

B14 多个集合链接，包含不同 UP 主或不同集合类型
├─ 并行或依次扫描 → 每个来源有独立进度、错误和重试入口
├─ 展开出重复内容 → 跨来源去重，仍可查看内容来自哪些集合
├─ 一组成功、一组失败 → 成功组可提交，失败组独立恢复
└─ 候选数过大 → 分组折叠 / 限制范围 / 分批提交

B15 集合扫描后的二次操作
├─ 打开某候选原链接 → 返回后保留扫描结果和选中状态
├─ 搜索 / 排序 / 筛选 → 改变可见集，不应意外改变已选集
├─ 刷新扫描 → 新增 / 消失 / 重复候选的选中状态处理
├─ 更改扫描范围 → 提示是否保留已选项
└─ 关闭或返回修改 → 重新进入时恢复或明确丢弃未提交选择
```

### B16～B20 候选确认、参数和归类分支

```text
B16 候选选择
├─ 0 条选中 → 禁止提交 / 提示至少选择一条
├─ 1 条选中 → 单任务确认语义
├─ 多条选中 → 显示批次数量、预计任务数和部分失败规则
└─ 选中项中包含重复 / 不可用项 → 分别标记可提交、跳过和需处理数量

B17 总结参数
├─ 整批使用同一模板 / 强度 / 模型
├─ 对某一条使用不同参数
├─ 修改整批参数后保留或重置单项覆盖
└─ 参数不可用 → 去设置 / 改用可用参数 / 保留当前选择待返回

B18 标签与收藏夹
├─ 不归类 → 直接提交为未分类内容
├─ 整批归入已有收藏夹 / 标签
├─ 创建新收藏夹 / 标签 → 成功后回到确认状态
├─ 不同来源组归入不同收藏夹
└─ 归类保存失败 → 保留候选和参数，可重试或改为不归类

B19 确认窗口中的导航与恢复
├─ 关闭 → 原输入、识别结果和候选选择保留 / 明确丢弃
├─ 返回修改 → 改链接后只重查受影响条目
├─ 切换主导航 → 离开警告 / 草稿保留 / 返回恢复
└─ 刷新或应用重启 → 草稿恢复 / 明确清除

B20 确认前的重复与状态变化
├─ 候选在查询后被其他任务提交 → 提交前重检并刷新状态
├─ 候选已在处理中 → 跳转现有任务 / 跳过 / 允许新建
└─ 候选已在知识库 → 打开现有内容 / 重新总结 / 跳过
```

### B21～B26 提交、任务和后续延伸分支

```text
B21 提交请求
├─ 首次点击 → 按钮禁用 / 显示提交中 / 可取消条件
├─ 连续点击 → 阻止重复或复用同一提交结果
├─ 提交期间关闭窗口 / 离页 → 明确后台继续、取消或可恢复状态
└─ 网络中断或超时 → 查询服务端结果 / 安全重试 / 避免重复创建

B22 提交结果
├─ 全部成功 → 显示已创建数量 → 查看任务 / 继续接入
├─ 部分成功 → 成功项进任务，失败项留在确认区重试 / 修改 / 删除
├─ 全部失败 → 保留所有输入、选择和参数 → 重试 / 返回修改
└─ 重复项被跳过 → 区分“新建成功”与“已有复用”

B23 提交后的输入区处理
├─ 单条成功 → 清除对应输入行
├─ 集合中所有选中项成功或跳过 → 清除对应集合输入行
├─ 一个原输入展开的选中项部分失败 → 保留该原输入及失败上下文
└─ 混合批次部分成功 → 只清除已解决的原输入行

B24 任务等待与处理
├─ 单任务 → 暂停 / 恢复 / 取消 / 查看来源 / 调整队列顺序
├─ 批量任务 → 批量暂停 / 仅操作单项 / 继续其他项
├─ 部分失败 → 仅重试失败项 / 更改失败项参数 / 删除失败项
└─ 离页 / 刷新 / 重启 → 当前阶段、进度、已完成项和失败项可找回

B25 任务终态
├─ 全部完成 → 打开批次结果 / 打开某一条 / 进入知识库对应分类
├─ 部分完成 → 查看已完成内容 / 重试失败项 / 放弃剩余项
├─ 全部失败 → 查看共同原因和单项原因 / 批量重试 / 返回来源重新接入
└─ 已取消 → 保留已完成结果 / 重新创建未完成项 / 删除记录

B26 入库后的延伸操作
├─ 从任务打开内容 → 返回时保留任务筛选、展开和滚动位置
├─ 从知识库打开内容 → 返回时保留搜索、分类、收藏夹和筛选上下文
├─ 打开上一条 / 下一条 → 明确相邻顺序基于批次、当前筛选或全库
├─ 编辑标签 / 移动收藏夹 / 收藏 → 保存中 / 成功 / 失败恢复
├─ 重新总结 / 局部总结 → 新任务 / 版本生成 / 旧版保留 / 失败回退
├─ 打开证据、目录或原链接 → 返回后保留阅读位置
├─ 提交反馈 → 发送中 / 成功 / 失败重试 / 防重复提交
└─ 删除 → 进回收站 → 恢复 / 彻底删除 / 恢复后原分类去向
```
