已知兼容网关可返回任一受支持的最终消息结构。结构化响应优先于聚合字符串。无成品、明确截断或发现草稿时，使用同一份来源重试一次。第二次结果仍异常则走原有总结失败入口。恢复任务若发现旧总结检查点混有草稿，回到已有分段重新生成。正文规则忽略 Markdown 引用和代码围栏里的示例，对无法辨认的混合文本存在漏检边界。
