# 桌面原生控件与任务反馈解决方案

当前桌面主页面存在 2 个原生模型候选框、5 个原生下拉控件和 3 个原生文本弹窗入口。设置输入框没有专用焦点样式。批量重试借用全局浮动提示条显示持续进度。

| 编号 | 实施 | 验收 |
| --- | --- | --- |
| R1 | 总结模型与云端转写模型使用产品候选列表，设置输入框统一焦点样式 | 模型识别后可点选或键盘选择，保留手动输入和保存，未选择时可继续编辑 |
| R2 | 导入、重新总结的风格和强度，以及本地转写模型，使用产品下拉样式 | 五处可鼠标和键盘选择，初始值及提交行为与现有流程一致 |
| R3 | 新建标签、新建收藏夹和更改导出目录使用产品弹窗 | 确认执行原有动作，取消可返回且不写入 |
| R4 | 批量重试在任务面板内显示进度，普通全局提示采用产品配色 | 模拟批量重试可见项次、成功和失败数，最终提示仍可读 |

限定当前桌面主页面。系统文件选择器、桌面壳启动错误提示、旧版和开发调试页不纳入。运行验证用模拟数据，避免变更真实任务队列。
