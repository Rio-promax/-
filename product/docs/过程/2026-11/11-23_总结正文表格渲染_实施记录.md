# 总结正文表格渲染

截图中的「层级｜含义｜材料中的例子或状态」在总结详情页显示为普通段落。现由正文渲染器根据表头和分隔线生成表格，兼容首尾有竖线且行间有空行的写法。单元格原文按列自然换行，后续标题接在表格下方。已有正文重新打开即可显示。

## 验证

- 定向 Node 测试 4 项通过，覆盖表格原文、行间空格分隔后的续接、普通竖线段落、转义和知识库分组回归。JavaScript 语法检查和界面改动的 diff 检查通过。
- Chrome 使用模拟接口打开真实详情页，确认三列表头、三行正文、长文字自然换行、原文完整、后续标题在表格外。
- 全量 Node 4 项通过，2 项模型自动发现测试因缺少函数声明失败，提交前的 HEAD 同样缺少这两个声明。全量 pytest 687 项通过、93 项失败，本轮未逐项比对 pytest 基线。
- 实际桌面壳打开用户原笔记待人工验收。
