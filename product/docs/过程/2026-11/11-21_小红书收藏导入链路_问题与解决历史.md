- 平台范围：设置页与连接检查**只含 B站 + 小红书**；知乎/抖音/微信保留定义但不显示、不检查。

- `read_note` 失败时不建内容，宁可报「未读到正文」，不产出 404 页垃圾记录。

### R1 收藏分页

1. 在同一个已登录的产品小红书 WebView、同一收藏范围内，每组从首屏开始。先固定手动滚轮，对照直接进入收藏 URL 和站内点击进入。再固定能翻页的入口，比较手动滚轮、当前脚本与候选壳输入。分别记录真实滚动容器位置、末卡是否入视口、请求是否发出、响应是否到达、新增去重数。
2. 由对照结果选择最小改动。若只有站内入口能翻页，先修入口并复测；若同一入口手动能翻而脚本不能，验证壳内固定且有限的滚动步进，再接入现有 DOM 与分页响应观察。如果手动也无法翻页，记录原生页面表现并保留已读候选。
3. 用明确超过 10 条的收藏验收候选增长、去重和可选。仅凭同次扫描同一收藏范围的有效末页响应或可明确确认的列表末页标识，才能标完成。无增长、超时或达到扫描上限时保留候选，选择页持续显示未读完整。分别验收完整与部分结果。

### R2 笔记打开与导入

1. 同一收藏页手动点击之前失败的卡片和一张已知可读的对照卡，记录详情以页面导航还是浮层打开、目标 ID 从哪里确认、是否读到正文。只有在该笔记直接打开成功有实测证据时，才采用直接导航。
2. 若原生卡片可打开，按稳定笔记 ID 和收藏范围打开对应卡片。若为浮层，从实际打开的详情核对目标 ID 和非空正文，读完关闭浮层；若导航离开列表，读完恢复原收藏范围和加载进度。当前 DOM 没有下一张目标卡片时重新定位或分页到该卡片，按固定边界停止。找不到卡片、页面明确不可浏览、已打开但正文未读到、后端入库失败分别保留结果；壳读取失败不发入库请求。
3. 验收同批勾选首屏和后续页，切换筛选后核对选择集合。批次覆盖未导入的可读笔记、已有内容、壳读取失败及后端入库失败。核对目标 ID、正文、创建任务或复用结果，重试只处理失败项。
