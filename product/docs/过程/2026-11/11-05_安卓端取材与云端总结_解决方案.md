# 安卓端取材与云端总结：实施方案

> 状态：部分完成；产品账号、逐用户数据隔离和设备取材接口已实现并通过定向自动检查；APK、设备交互和生产 HTTPS 入口待验证。
> 范围：Android 单条内容取材、产品账号登录、云端按用户隔离总结与归档，以及本地 Android 环境构建和验证。

## 目标与依据

将小红书单篇笔记、B站单条视频的取材放到 Android 设备执行。平台账号会话留在设备；云端只接收总结所需的内容和最少来源元数据。云端按产品账号隔离任务、转写、摘要、附件、搜索索引和问答记录。

本方案执行用户已批准的测试与改造范围。已确认：产品增加账号登录与令牌；转写按用户隔离保留，清理临时采集数据；首期仅覆盖小红书单篇笔记和 B站单条视频。用户要求“开始”后，本轮按推荐方案关闭公开注册，由管理员建号；现有单用户数据不会自动分配，迁移操作必须显式指定目标账号，本轮不迁移现有库。

实现前核对了产品五图、[产品文档索引](../../README.md)、[核心服务代码地图](../../../src/services/core/README.md)、[AI 代码执行标准化方案](../../基线/规则/AI代码执行标准化方案.md)、现有 Android 壳与 API。现状依据另见[技术风险记录](../../基线/路线/安卓端取材与云端总结_技术风险记录.md)。

## 已确认边界

- Android 端直接访问平台并完成登录态下的单条取材；不得将平台 Cookie、Token、密码、登录账号、原始请求头或 WebView 登录资料发送至产品云端。
- Android 壳不得展示或复制平台 Cookie。平台会话只供该设备的 Android 应用使用，不进入产品账号身份。
- 产品 API 使用产品账号身份和会话令牌，不以反向代理 Basic Auth 用户名作为数据归属。服务端不得接受客户端自行声明的 `user_id`。
- 云端接收经字段白名单校验的标题、平台、规范链接及摘要所需文本；保留该用户的转写和摘要，删除音视频、网页快照、抓取缓存及可重建临时文件。不得记录正文、令牌或平台凭证。
- 只实现小红书单篇笔记与 B站单条视频。暂不增加批量、收藏夹或全量扫描。
- 总结、转写、索引、来源引用、摘要版本和问答继续按用户身份保存。不得因清理临时内容而删除用于 RAG 引用和重新总结的用户转写。
- 第三方内容采集遵循平台实际可用能力，不绕过限制；异常状态可单独关闭对应平台入口。

## 模型服务商留存核查

仓库默认总结接口为 OpenAI `/v1/chat/completions`，默认 ASR 接口为 Groq `/openai/v1/audio/transcriptions`；实际服务器账号当前使用的供应商配置未读取。OpenAI 说明 API 内容默认不用于训练，但滥用监测日志可能含输入/输出并保留最多 30 天；符合资格的账号可申请 Zero Data Retention。Groq 说明推理数据默认不保留，但可靠性排障或滥用调查可能临时保留最多 30 天，且可在数据控制中选择退出。上线前须按实际配置与账号控制核对，不能将“本服务临时文件已清理”等同于第三方即时删除。

依据：[OpenAI API 数据控制](https://developers.openai.com/api/docs/guides/your-data)、[GroqCloud 数据说明](https://console.groq.com/docs/your-data)。本轮使用隔离测试服务，不向真实模型 API 发送内容。

## 需求与实施映射

### R1 · 产品账号、令牌与旧数据归属

增加产品内登录和会话令牌；公开注册关闭，账号由本机管理员命令创建。服务端仅保存口令派生值与令牌哈希；会话令牌通过 `HttpOnly`、`SameSite=Strict` Cookie 提供给同源 UI，Android 分享请求从应用 WebView 会话附带产品会话。退出会撤销令牌；未认证 API 返回 401。产品令牌不得记录、复制或放入分享文本。管理员创建的任何账号均不自动继承现有单用户数据。

### R2 · Android 端单条取材

分享链接进入 Android WebView 后，由设备页面 DOM 读取小红书单篇正文；B站仅从页面 `video.textTracks` 读取带时间戳的字幕轨道，无可用字幕时不伪造转写或提交。设备契约测试检查采集脚本与提交字段；APK 构建、WebView 页面读取和真实平台账号流程未验证。

### R3 · 最小云端请求与传输

Android 仅向产品 API 提交平台、标题、规范链接、正文和可选时长；请求模型拒绝未知字段，后端校验平台与来源链接。产品登录和 Android 分享提交都强制 HTTPS；分享提交关闭自动重定向，避免 HTTPS 请求被降级到 HTTP。测试覆盖伪造用户字段和越权来源；当前壳仍配置公网 HTTP，因此分享提交会安全失败，需先核实并配置生产 HTTPS 入口。

### R4 · 用户数据隔离

每个产品身份的任务、归档附件、转写、摘要、索引、问答、标签、收藏夹、设置与平台连接状态互不可见。所有读取、更新、删除、导出和异步任务恢复均须在服务端验证归属；跨用户 ID 猜测不得返回另一用户内容。存储边界必须同时覆盖数据库、归档目录和临时目录。

实现约束：当前 `create_app` 装配单个 `SQLiteStore`、`AnalysisWorkflow`、`LocalJobQueue` 与归档根目录；大量路由闭包直接使用该实例，扫描进度、链接查询和后台 worker 也在应用级状态中。采用共享认证入口按已验证的账号分发到独立 API 运行实例；每账号使用独立 SQLite 数据库、归档目录、临时目录、索引和进程内状态。内容、任务、标签、收藏夹、模型设置和平台连接均由对应实例的数据库承载；共享账号库只保存账号与会话。每个用户实例保留私有任务视图，分析任务仍通过进程级单并发门控，避免多账号同时占用本地 ASR 内存。客户端不能选择 `user_id` 或内部实例路径。

### R5 · 转写留存与临时清理

归档中的 `transcript.json` 继续作为该用户问答引用与重新总结依据。临时音视频、网页/接口快照、抓取中间文件和可重建检查点在成功后清除；失败、超时、取消、重试、进程重启和删除任务也按边界清理。共享账号实例启动时，在恢复任务前只删除账号临时根目录下遗留的 `asr-segment-*` 分段目录；测试确认不触碰其他目录。日志、诊断、备份和导出不得意外包含平台凭证。配置的总结服务商收到正文的字段及外部留存政策需在上线前核对；本轮用本地假服务验证，不调用真实账号或生产模型。

### R6 · Android 壳与运行链路

构建并安装当前源代码 APK，验证首次安装、升级、冷启动、产品登录、首页、系统分享、返回键、平台登录/会话过期、后端离线和恢复。核对 `capacitor.config.json`、`ShellConfig`、网络安全配置和分享入口的服务地址；令牌和平台会话不通过日志、剪贴板或系统备份泄露。

### R7 · 隔离后端与端到端验收

测试服务的数据库、归档、日志和临时目录全部位于 `product/local/android-test/`，不得访问个人知识库或现有公网服务。使用两个独立测试账号覆盖登录、内容提交、任务和摘要归属、附件/搜索隔离、退出后拒绝访问。模拟器完成的行为按证据记录；真机后台存活、不同 Android 版本及实际平台账号路径列为待人工验收。

## 实施顺序

1. 已完成代码路径与运行环境盘点；由于可用内存不足且用户选择暂缓，本轮未启动模拟器或重建 APK。
2. 已实现管理员建号、产品会话令牌、认证网关，以及按账号隔离数据库、归档、临时目录、模型目录与运行状态；旧库不自动迁移。
3. 已实现设备单条取材、白名单提交、会话 Cookie 认证与临时工作目录隔离；平台 Cookie 保留在设备 WebView。
4. 已完成后端/API 与 Android 源码契约自动检查；生产 HTTPS 入口、APK 构建、模拟器和真实平台路径仍待验证。首轮独立审核发现分享明文传输风险和 ASR 临时目录重启遗留，两项均已修正并增加回归检查。
5. 本轮完成后更新本方案、当前进度台账与移动壳说明，提交本轮明确文件，并进行只读独立代码审核。
