# 产品交互全链路自测与首轮走查

适用对象为桌面产品的用户任务。沿用 [产品状态机审核](../../../../.agents/skills/product-state-machine-audit/SKILL.md) 的状态、转换和证据口径，补充以下执行步骤。

## 可复跑步骤

1. 先列用户任务及其可见完成信号。按主导航、跨页链路和异步动作建覆盖表，记录数据前置条件和可执行范围。先跑「知识库 → 合集 → 笔记 → 收起栏 → 恢复 → 返回合集 → 返回总览」，再跑「内容接入 → 任务 → 结果 → 知识库 → 问答」及设置的独立操作路径。
2. 每步先按正常视口寻找入口，再定位自动化元素。按认知走查检查用户能否知道该做什么、看到入口、理解它会做什么、点击后看懂进展。记录入口是否在视口内、能否操作、返回的实际目的地和是否保留筛选、位置与布局。应用内返回、主导航、浏览器返回或桌面壳返回按实际支持分别验证。
3. 异步动作同时记录点击、请求发出、请求响应、可见反馈、业务终态。先跑真实成功，再用受控延迟和失败复跑，标记注入条件。单测能证明的数据结果、浏览器能证明的可见行为及服务端能证明的业务完成分别标记。对于有副作用的任务，用隔离数据观察重复点击、超时、失败重试、离开后回来和结果可找回。
4. 逐个对照来源页、任务列表、详情和结果是否描述同一对象及阶段。请求成功后继续检查产物能否打开。固定路径转成可重复的可见断言。用用户能看到的名称和状态判断是否通过，失败时留截图、DOM 或网络追踪，避免把真实账号数据或令牌放进共享证据。
5. 最后复核正常、慢速、失败、退出、返回和恢复的覆盖。每项写已验证、部分验证或未验证，并附复现步骤和缺口。自动化定位可以点中按钮，入口是否直观仍需单独判断。受控延迟可暴露反馈空窗，真实耗时和桌面壳行为需在对应环境取证。

## 2026-11-22 首轮实跑

本机当前工作区，Chrome + Playwright，1440 × 850，连接真实本地 API 与现有数据。抽样一条笔记、一个合集和一项已完成任务。没有提交新任务、发起模型处理或进行账号导入。

| 路径 | 操作和观察 | 结论 |
|---|---|---|
| A01 知识库搜索 | 输入无匹配词出现「没有符合条件的内容」，清空后恢复卡片 | 已验证 |
| A02 笔记快捷栏 | 收起后快捷栏及其控制同时隐藏，页面未发现展开按钮。正文从 936px 缩到 220px，目录从 220px 扩到 936px。返回总览再进入仍保持收起 | 已复现恢复入口和布局问题 |
| A03 笔记和合集返回 | 笔记底部「返回知识库」可点。从总览进笔记可回总览。从合集进笔记先回合集，合集内另有返回总览按钮。左侧知识库入口能从笔记返回库页面 | 已验证实际路由。底部入口的可发现性和合集内返回文案另行评估 |
| A04 知识库刷新 | 真实 history 请求额外延迟 1.25 秒，待响应时按钮仍显示「刷新」且可再次点击，无可见处理中提示。请求返回 200，抽样数据相同，未出现单独的完成提示。注入 503 后出现「刷新失败」与重试提示 | 已复现等待空窗。失败提示已验证，真实延迟、重复请求后果和失败后实际重试未验证 |
| A05 已完成任务打开结果 | 任务页点击「查看结果」打开有正文的笔记。详情底部按钮回知识库，左侧任务入口可重新进入任务。原列表上下文未验证 | 已验证既有结果可打开，详情内未走原路返回任务 |
| A06 一级入口和空链接 | 主导航可进入内容接入、任务、知识库、AI 问答、设置。空链接点击「查询」出现「请先粘贴链接」 | 入口和空输入已验证，业务链路覆盖仍为部分 |

## Playwright MCP 五区复核（2026-11-22）

环境为 Playwright MCP 0.0.86、Chrome 1440 × 850、真实本地服务。查询真实本地数据，延迟投递指定 GET 响应来观察等待状态。链接提交和问答 POST 用浏览器内的受控响应，保护现有数据并避免触发外部模型。注入结果只证明前端面对这些响应的行为。

| 编号 | 路径 | 实测现象和复测判据 |
|---|---|---|
| P2-01 | AI 问答 → 输入 → 发送 → 等待 | 立即出现用户提问气泡，约 1.9 秒的受控等待期间没有生成状态，发送仍可用。503 到达后出现错误行，输入框已清空。复测应能从气泡旁看到等待及终态，并能取回问题后重试。 |
| P2-02 | AI 问答 → 发送 → 取消 | 延迟 5.5 秒的模拟请求期间点击取消，未见取消通知或请求取消信号，原请求仍收到 503 并显示「发送失败」。复测应区分清空草稿与取消已发送问题，展示操作结果。 |
| P2-03 | 任务 → 刷新列表、知识库 → 刷新 | 真实读请求均为 200，额外延迟 1.9 秒期间按钮文案不变、仍可点，无处理中提示。待反馈结束仍无可辨完成信号。复测分别检查等待、结果和失败。 |
| P2-04 | 知识库 → 笔记 → 收起快捷栏 | 控制入口随栏隐藏，正文宽度由 936px 变成 220px。返回重进仍收起。复测应可从当前页恢复快捷栏，正文保持可读。 |
| P2-05 | 内容接入 → 查询就绪 → 提交 | 受控确认响应等待期间提交按钮变灰，但仍写「提交」，预览仍写「可提交」。模拟失败后提示且保留输入。直接再点提交未发起新请求，未提示下一步。按「查询 → 提交」重新走后，模拟成功触发任务页和「任务已生成」通知。复测应让用户看懂等待阶段及重试方式。 |
| P2-06 | 设置 → ASR | 模拟模型列表请求延迟并返回 503。等待中左侧已选 ASR，右侧仍显示「平台」。请求失败后才显示 ASR 面板，无加载失败提示。复测应让失败与确实没有模型可区分。 |
| P2-07 | 设置 → 平台 → 环境自检 | 真实检查请求 200，等待期间按钮仍可点且无进度。完成后只提示「环境存在待处理项」，没有列项或可见详情入口。复测应能看到处理中和待处理项。 |
| P2-08 | AI 问答 → 设置 → 返回 | 实际落点为内容接入。复测应回到进入设置前的页面。 |
| P3-01 | 任务 → 查看结果 → 返回知识库 | 既有任务的正文可打开。详情按钮按名称返回知识库，用户若要退回来源任务页只能使用主导航。复测核对返回意图和任务上下文。 |

已走查空链接查询和提交、空文件识别和提交、预览失败、清空、任务编辑切换、任务结果、知识库筛选菜单层级、搜索无结果与恢复、回收站往返、合集与详情逐层返回、导出/删除/重新总结弹窗打开与取消、问答空输入/范围应用/折叠、设置四个分区。版本和更多按钮已触发，菜单内容与焦点未做充分断言。实测过程中未确认真实删除、恢复、导出、设置保存或重新生成。

### 任务状态与问答终态补测

- 用七条合成任务分别覆盖排队、进行中、保存进度、暂停、失败、取消和完成。出现插队、暂停、继续、重试、查看结果等对应入口。保存进度使用 switching 枚举。任务状态之间的真实服务转换仍待验证。
- P2-09 · 合成进行中任务点击暂停，1.8 秒受控响应期间同一行仍显示「暂停」，收到响应并重读列表后才显示「继续」。受控继续和重试也完成列表刷新。编辑态全选显示 7 项，取消全选显示 0 项。复测应在请求期间标记此行正在操作，同时校验按钮是否允许再次发起请求。
- 从任务页进入设置再点返回，也落到内容接入。P2-08 已在任务、问答两个来源上复现。
- 模拟问答成功响应后，提问和回答文本能在当前会话显示。刷新后恢复、切换会话后归属、取消的真实服务行为仍需核实。
- 暂存脚本和执行日志位于 product/local/tmp/playwright-mcp-audit。日志可能含少量当前页面文案，供本机复核。

## 服务端已保存后的界面同步复核

Playwright MCP 连接单独启动的真实本地服务，数据库为 SQLite 备份副本。通过另一客户端调用写入 API，随后以 GET 读回确认。浏览器响应未注入。

| 对象 | 服务端提交证据 | 打开页面的观察 | 恢复操作 |
|---|---|---|---|
| 知识库标签 | 创建返回 201，GET 标签列表按 ID 查到新标签 | 保持页面打开 5 秒未出现。先去任务再回知识库，等待 2 秒仍未出现。 | 点击知识库「刷新」，标签出现。 |
| 笔记分类 | 更新返回 200，GET 内容详情读回新分类 | 保持详情打开 5 秒仍显示旧分类。 | 返回知识库后卡片显示新分类，再打开笔记也显示新分类。 |

这些用例验证了外部客户端写入后的同步行为。同页发出写操作后的刷新逻辑，以及真实生成任务完成后的同步另行核验。

同页操作对照。通过知识库「新建标签」和「新建收藏夹」按钮提交真实写入，后端读回均存在，两项也都自动出现在当前知识库界面。

任务同步对照。使用副本数据库注入任务状态，真实任务 API 读回确认，无实际任务执行。列表初始全为完成、暂停或失败时，将一条已完成任务改为失败。API 已返回失败，7 秒后同一行仍是「查看结果」，切出再进仍旧，手动「刷新列表」后才变为「重试」。将同一行改为总结中并手动刷新作为对照，再注入失败。该次前端在 7 秒观察期内自动更新为「重试」。当前任务轮询仅在前端已知有活跃任务、列表可见且未进入编辑态时拉取。
