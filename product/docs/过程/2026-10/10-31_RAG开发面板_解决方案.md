# 10-31 RAG 开发面板 · 方案与执行指导

> 日期：2026-10-31。范围：本地开发诊断页与最小 query trace 补充。本文不修改 RAG 执行契约中的模型、预算、检索或质量参数；运行进展只记录在本节。

## 1. 已确认目标与边界

- 在现有 FastAPI 服务提供独立本地页面 /dev/rag，正式问答页不增加开发面板。
- 按会话和 query 查看真实运行记录；配置与模型身份只显示 provider、model、协议和 configured 状态，不返回或显示密钥。
- 展示回答模型、切块实现、索引覆盖、路由、检索候选、rerank 前后、证据检查、补查、实际耗时、Token usage 与错误。
- 字段没有记录或阶段没有执行时明确显示“未记录”或“未执行”。禁止从当前设置、代码推断出虚构的 query trace。
- rerank 保持现有默认关闭。独立真实诊断仅用于验证提供方可用性，不写入 query trace，不改变全局行为。
- 不新增切块模型、压缩模型、监测模型；不增加正式问答界面入口或用户产品功能。

## 2. 现状与采用方式

- 实际归档切块由 app/knowledge/chunking.py 的 chunk_transcript 完成：estimate_tokens 与 max_tokens 决定合并及长段切分，并继承输入字幕段的位置；代码中没有切块模型请求。
- app/knowledge/ask_index.py 已提供 FTS 与向量覆盖统计；search_hybrid 默认 rerank=False。
- app/knowledge/rag.py 的 query 记录已有路由、工具结果、引用、usage 和失败状态，但旧 trace 没有逐阶段耗时和底层异常类型。开发页不通过冷启动初始化 index，也不恢复 query 状态；覆盖读取只使用进程已初始化的 index。
- 向量覆盖原统计全扫 sqlite-vec 虚拟表并与索引表联接，实际 8,882 条向量耗时约 32.4 秒。开发页改读事务维护的状态记录计数，明确标注“未核验向量点”；`vector_coverage_snapshot()` 保留对 active vec 点的实际检查，其他调用者语义不变。冷 overview 只报告未初始化，避免首屏初始化或全表向量扫描。
- 采用同服务独立页、只读 overview API、既有 session/query API。只在缺失时补充非敏感的逐阶段耗时、候选摘要和异常类型；不存完整提示词或密钥。

## 3. 实施项

### R1 · 真实配置与模型调用诊断

通过既有问答设置 API，将实际数据库 ask_reuse_summary_config 设为 true，并确认问答读取总结配置。分别记录真实连接检查、问答路由、embedding 与 rerank 结果；失败原因以实际异常为准，不用 fake 结果替代。

### R2 · query trace

在现有 trace 中记录模型身份、每次模型调用的输入字节数、输出上限、usage 和耗时；失败时只记录异常类、cause 类、cause reason 类或 HTTP 状态，不保存 URL、响应正文或密钥。记录向量调用耗时、候选 ID 与位置、rerank 状态、证据校验摘要及总耗时。默认关闭的 rerank 对应状态为未执行。

### R3 · 独立开发页

新增 /dev/rag 页面，从已有 session 和 query API 选择记录，从只读 overview API读取当前配置与索引覆盖。细节使用默认折叠区；字段缺失时显示未记录，未执行阶段显示未执行。页面不触发真实模型调用。

## 4. 方案选择

| 做法 | 取舍 |
|---|---|
| 把面板嵌入正式问答页 | 可就地进入，但会把临时诊断内容带入正式产品界面 |
| 独立本地 /dev/rag 页面 | 复用现有会话/query 与 FastAPI，开发诊断和正式问答界面隔离；需要单独打开页面 |
| 外部诊断工具 | 与服务解耦，但需另行接入数据库和日志，容易产生第二套数据读取路径 |

采用独立本地页面；这是已确认范围。页面使用现有 API 和当前 query trace，overview 仅返回非敏感配置及索引统计。

## 5. 验收与保护范围

- 通过现有 API 读取并选择会话及 query；状态、模型、调用、候选、引用、usage、错误只显示服务实际返回的数据。
- 配置接口响应和页面均不包含 API key 或完整敏感 URL。
- 对已失败且无阶段记录的旧 query，显示失败与原始耗时；阶段细节显示未记录，不回填推断值。
- 通过浏览器打开 /dev/rag；验证加载 overview、选择 query、折叠细节及接口错误状态。
- 检查问答页未增加开发入口；rerank 默认关闭，页面加载不发模型请求。
