## 二、第一阶段目标

第一阶段解决统一平台识别、账号链接识别、平台连接状态、单条内容导入，以及图文/视频内容的文字提取：

```text
输入链接
→ 识别平台和对象类型
→ 判断公开读取或登录条件
→ 预览（确认前：预计可读取 / 预计缺失）
→ 用户确认导入
→ 平台适配器提取内容
→ 转换成现有统一内容对象
→ 进入现有任务队列
→ 归档到现有知识库
→ 归档后展示实际完整性
```

支持范围：

| 平台 | 账号识别 | 单条内容识别 | 本阶段导入能力 |
|---|---|---|---|
| B站 | UP 主 | 视频、图文 | 视频：复用并标准化现有能力；**图文：需新增图文路径（P10）** |
| 小红书 | 用户主页 | 图文笔记、视频笔记 | 新增平台适配（P7、P9） |
| 抖音 | 用户主页 | 单条视频 | 新增平台适配（P8） |
| 知乎 | 用户主页 | 问题、回答、文章 | **仅识别 + 降级导入（2026-09-20 用户决策 D1：未登录公开读取实测基本不可读，P6 收缩）** |

账号识别表示识别主页、平台和可获得的基本信息，**不表示**读取账号的全部发布内容或私人收藏。

**账号能力口径（统一）**

- 本阶段四个平台对"账号"只做到：识别主页链接、识别平台、读取公开可见的基本信息。
- 产品现有 B站 收藏扫描端点（`/api/v1/imports/bilibili/favorite-scans/*`，`app/api/main.py` 第 2329、2339 行）**维持现状**：作为既有能力保留并纳入回归验收，但**不向小红书、抖音、知乎推广**，也不作为本阶段任何新平台的参考实现。
- `SourceEnumerator`（`app/ports/providers.py` 第 86 行）只预留接口位置，本阶段不实现任何平台的账号内容枚举。

## 三、强制复用规则

执行 Agent 必须按以下顺序作出技术决策：

```text
1. 直接调用已有功能
        ↓ 不满足
2. 在已有功能外增加平台适配层
        ↓ 仍不满足
3. 复制最接近的已有模块并做平台改造
        ↓ 仍不满足
4. 新建最小必要模块
```

### 复用约束

1. 未检索现有模块前，不得创建新模块。
2. 已有接口能通过参数或适配器满足时，不得创建平行接口。
3. 复制已有模块前，必须说明直接调用为何不成立。
4. 新建模块前，必须说明调用和复制改造为何都不成立。
5. 不得另建登录体系、凭证存储、任务队列、错误体系或知识库归档流程。
6. 平台差异放在平台适配器内，不向 API 主入口持续堆积条件分支。
7. 复用时必须适配平台真实差异，不能把 B站字段和行为原样套到其他平台。
8. **能力只允许有一个真相源**：平台能力以 `PlatformDefinition` 为唯一静态定义源，接口返回的能力结构只能由它派生（见 §6.2）。

### 执行前复用判断表

每个执行包开始前必须填写：

| 项目 | 说明 |
|---|---|
| 已检查模块 | 实际检索过的代码、接口和测试 |
| 直接复用 | 原样调用的能力 |
| 适配复用 | 通过参数、包装或接口适配复用的能力 |
| 复制改造 | 复制来源及不能直接调用的原因 |
| 必须新建 | 新建内容及前三种方式不成立的证据 |
| 不采用方案 | 放弃的替代方式和原因 |

## 五、统一接口与状态契约

### 5.1 平台识别结果

```json
{
  "platform": "xiaohongshu",
  "source_type": "image_post",
  "object_label": "图文笔记",
  "canonical_url": "https://...",
  "platform_content_id": "...",
  "requires_login": false
}
```

平台对象类型（`source_type`）取值：

- `account` / `video` / `image_post` / `article` / `question` / `answer` / `collection` / `unknown`

`object_label` 是 `source_type` 的中文标签，供界面直接展示，不得由前端各自硬编码翻译。

### 5.2 平台对象类型 → 内容类型的映射（定稿）

**不得新增 `ContentKind` 枚举值。** 现有 `ContentKind`（`app/domain/models.py` 第 24～29 行）只有 `video` / `audio` / `article` / `image` / `pdf`；新增枚举值会牵动归档、筛选与展示多处。问答关系改用专用字段表达。

| `source_type` | 映射 `PreparedSource.kind` | 关系表达 |
|---|---|---|
| `video` | `video` | 转写、字幕走现有 ASR 流程 |
| `image_post` | `image` | 图片序号 + OCR 归属字段 |
| `article` | `article` | — |
| `question` | `article` | 问题正文进入内容；由 `platform_source_type` 标记来源为问题 |
| `answer` | `article` | 问答关系由专用字段表达（见 §5.4） |
| `account` | 不产生内容 | 仅识别 |
| `collection` | 不产生内容（本阶段） | 仅识别 |
| `unknown` | 拒绝导入 | 给出用户文案并结束 |

**适用范围说明（2026-09-20 复审补充）**：`account` 与 `collection` 的"不产生内容、仅识别"仅约束**新平台**（知乎、小红书、抖音）。B站 现有 UP 主主页与收藏夹链接维持既有候选扫描流程（§2 账号能力口径），用户确认后才创建任务，不按本表拦截。

### 5.3 平台连接接口

```text
connect(platform, authorization_input)
probe(platform, protected_credential)
disconnect(platform)
```

统一返回字段：

```text
status
account_label
message
checked_at
suggested_action
```

统一连接状态（与 `app/platforms/connections.py` 第 10～19 行一致，8 值）：

- `NOT_CONNECTED`
- `CHECKING`
- `CONNECTED`
- `EXPIRED`
- `REAUTH_REQUIRED`
- `RISK_CONTROLLED`
- `TEMPORARY_ERROR`
- `UNSUPPORTED`

临时错误不得覆盖已经保存的有效连接状态。

### 5.4 内容准备接口

```text
URL + 平台凭证
→ 平台适配器
→ PreparedSource
→ 现有任务创建
→ 现有知识库归档
```

统一内容至少包含：标题、作者、平台、平台内容 ID、平台对象类型、内容类型、原链接、规范链接、发布时间、正文或转写、封面、获取方式、来源说明和内容指纹。

图片顺序、OCR 归属、问题—回答关系等内容应先检查现有字段；只有现有对象不能准确表达时才补充结构。**P1 需核对的候选新增字段**：

```text
platform_content_id      平台内容 ID
platform_source_type     平台对象类型（§5.1）
image_index              图片序号（image_post 用）
ocr_attribution          OCR 文本归属的图片序号
qa_relation              问题—回答关系
completeness             内容完整性（§5.5）
platform_warning         平台警告
```

### 5.5 预览两段契约（本章新增，解决"预览字段没有接口来源"）

现有探测响应 `SourceProbeResponse`（`app/api/schemas.py` 第 328～337 行）只有 `url` / `platform` / `kind` / `source_type` / `duplicate` / `requires_login` / `material_hint` / `next_action` / `can_import` 九项，装不下预览页需要的内容。因此**预览必须分两段**：

**第一段 · 确认前（探测 + 轻量预读）**

必须新增字段：

| 字段 | 说明 | 来源阶段 |
|---|---|---|
| `object_label` | 对象类型中文标签 | 探测 |
| `canonical_url` | 规范链接 | 探测 |
| `fetch_way` | `public` / `credential` | 探测 |
| `expected_readable` | **预计**可读取内容（数组，如 `["标题","正文","图片文字"]`） | 探测 |
| `expected_missing` | **预计**缺失内容（数组，如 `["视频画面文字"]`） | 探测 |
| `degrade_options` | 降级方式（数组，如 `["上传本地图片","上传本地视频"]`） | 探测 |
| `preview_title` | 标题，**可为空** | 轻量预读 |
| `preview_author` | 作者，**可为空** | 轻量预读 |

硬约束：

- 探测阶段返回的一律是**预计值**。字段语义与界面文案都必须体现"预计"，**不得**在确认前宣称"可以完整读取"。
- `preview_title` / `preview_author` 允许为空，界面必须有占位文案。
- 预读超时上限、重试次数、以及"预读失败是否可以继续导入"由 P1 冻结。

**第二段 · 导入后（读取完成）**

必须新增字段：

| 字段 | 说明 |
|---|---|
| `completeness` | `complete` / `partial` / `unknown` / `unavailable` |
| `missing_parts` | 实际缺失项（数组） |
| `platform_warning` | 平台警告 |

展示位置：内容详情与任务详情；**不覆盖**确认前的预览区。

### 5.6 用户状态流程（重排）

```text
待识别
→ 正在识别
→ 正在预读（取标题与作者；仅系统超时自动跳过，不提供用户跳过按钮）
→ 预览已就绪（确认前：只展示"预计可读取 / 预计缺失"）
→ [用户确认导入]
→ 正在读取
→ 正在解析
→ 已创建任务
→ 已进入知识库
→ 判定并展示实际完整性
```

要点：

- "是否会完整读取"属于**读取完成后**的结论，不作为确认前的承诺。
- "跳过"指预读超时后系统自动进入「预览已就绪」，不是用户操作；超时上限由 P1 冻结（§5.5）。
- 确认前的预览只回答"预计能拿到什么、预计拿不到什么"。
- 失败时保留原链接和识别结果，允许重试、重新连接或改用降级入口（§8）。

### P5 · 图片文字识别（OCR）— 新增执行包

**目标**：为图文笔记与视频关键帧提供稳定的"图片文字 → 文本"能力，输出必须能归属到具体图片编号。

**前置**：P1 第 8 项产物（OCR 选型与成本实测结论）。本包只冻结契约与失败规则，**不预设**技术选型。

**必须新建**：`app/adapters/vision/ocr.py`（新子包，与 `app/adapters/asr`、`app/adapters/summary` 并列）。

**复用**：优先复用 `app/adapters/summary/openai_compatible.py` 或 `app/adapters/asr/openai_compatible.py` 的调用骨架与接口形态；凭证复用 `protect_secret` / `unprotect_secret`。

**输入输出契约（必须冻结）**：

```text
输入：图片文件路径列表 + 每张图的序号
输出：[{index, text, status}]
      status ∈ {ok, empty, failed}
```

**约束**：

- 图片顺序不得改变；输出必须带图片序号。
- **单张失败不得使整条内容失败**：失败图片在结果中显式标记，并使内容 `completeness = partial`。
- 不得把 OCR 失败当成空文本静默处理。
- 临时原图的使用与清理规则见 §6.12。

**验收**：

- [自动] 图片顺序不变。
- [自动] 每段文本都带正确的图片编号。
- [自动] 单张失败不破坏其余结果，且该图片被标记。
- [人工] 真实图文笔记的图内文字可读、归属正确。

**对其他包的约束**：P5 通过验收前，P7 / P8 / P9 / P10 中一切 OCR 相关验收一律标为**"未支持"**，不得标为"待验收"，也不得写成已实现能力。

## 八、统一异常与降级规则

| 技术原因 | 用户状态 | 下一步 | 降级入口（界面动作） |
|---|---|---|---|
| 链接格式错误 | 无法识别此链接 | 修改或重新粘贴 | 无 |
| 内容不存在 | 内容已删除或不可访问 | 返回或更换内容 | 无 |
| 需要登录 | 连接平台后继续 | 去连接 | 非 B站 平台："暂不支持自动验证，可改用公开内容导入或本地文件" |
| 登录失效 | 登录状态已过期 | 重新连接 | 仅 B站 |
| 平台风控 | 平台暂时限制访问 | 稍后重试 | 提供"改用本地文件"按钮 |
| 正文不足 | 未获得足够内容 | 截图、粘贴文本或上传文件 | **"改用本地文件" → 切到 `#local-input-panel`，保留原链接**；粘贴文本走 `#text-entry-dialog` |
| 视频不可读取 | 暂时无法取得音视频 | 重试或上传本地媒体 | **"改用本地文件" → `#local-input-panel`** |
| 临时网络错误 | 连接暂时失败 | 保留输入并重试 | 无 |

底层 HTTP、解析器、Cookie 和堆栈信息只写内部日志。若用户原因和下一步相同，优先复用已有错误，不增加新的用户错误类型。

**降级路径硬要求**：从失败状态切到「本地识别」页签时，**原链接与识别结果必须保留**在输入区，不得清空；用户切回「平台链接」页签时仍能看到原链接与重试入口。
